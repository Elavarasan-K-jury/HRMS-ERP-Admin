# `app/layouts/auth.vue` — Authenticated Super Admin Layout

## Purpose

Layout used for super admin pages after login. Provides sidebar navigation, header with breadcrumbs, and color theme picker.

## Template Structure

```vue
<template>
  <div :style="{ backgroundColor: themeStore.bgColor }">
    <UiSidebar :menu-items="menu" :title="title" />
    <UiColorSidebar />
    <div :class="sidebar ? 'ml-[250px]' : 'ml-[85px]'">
      <UiHeader :breadcrumbs="breadcrumbs" @toggleSidebar="toggleSidebar" />
      <main><slot /></main>
    </div>
    <UiLoader v-if="preloader" />
  </div>
</template>
```

## Script Logic

```js
import { menu } from '../data/menu'
const authStore = useAuthStore()
const themeStore = useThemeStore()
const title = 'JURY-HRMS'

// Breadcrumb resolution
function findBreadcrumb(menuGroups, path, parents = []) {
  for (const group of menuGroups) {
    for (const item of group.items) {
      if (item.path === path) return [...parents, group.group, item.label]
      if (item.children) { /* recursive search */ }
    }
  }
  return []
}
```

## Explanation

- Background color is dynamic, sourced from `themeStore.bgColor` (persisted in localStorage).
- Sidebar collapses from 250px to 85px wide based on `themeStore.sidebar` toggle.
- Breadcrumbs are auto-generated by recursively searching the menu structure for the current route path.
- On mount, loads local auth data and theme color, then shows a 1-second preloader.
- "Powered by Jurysoft" badge in bottom-right corner.
