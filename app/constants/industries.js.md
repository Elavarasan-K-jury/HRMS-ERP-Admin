# `app/constants/industries.js` — Industry Sector Constants

## Purpose

Provides a comprehensive list of 60+ industry sectors for organization profile selection.

## Data Format

```js
export const industries = [
  { label: 'Information Technology & Services', value: 'it-services', icon: 'lucide:cpu' },
  { label: 'Software (SaaS / Product)', value: 'software', icon: 'lucide:code' },
  // ... 60+ industries
  { label: 'Artificial Intelligence', value: 'artificial-intelligence', icon: 'lucide:sparkles' },
]
```

## Category Coverage

- **Technology**: IT, Software, Hardware, Telecom, Cybersecurity, AI, Semiconductors
- **Commerce**: E-commerce, Retail, Wholesale
- **Finance**: Banking, Financial Services, Insurance, FinTech
- **Healthcare**: Providers, Pharma, Biotech, Medical Devices
- **Education**: K-12, Higher Ed, EdTech
- **Manufacturing**: General, Automotive, Aerospace, Chemicals, Textiles
- **F&B / FMCG**: Food & Beverage, FMCG
- **Construction**: Real Estate, Architecture, Civil Engineering
- **Logistics**: Supply Chain, Warehousing, Shipping, Aviation, Railways
- **Energy**: Oil & Gas, Power, Renewables, Mining
- **Media**: Entertainment, Advertising, Gaming, Publishing
- **Professional Services**: Consulting, Legal, Accounting, HR/Staffing
- **Hospitality**: Hotels, Travel, Events, Sports
- **Agriculture**: Farming, AgriTech, Forestry, Fisheries
- **Public Sector**: Government, Non-profit, Defense
