# `.gitignore` — Git Ignore Rules

## Purpose

Defines which files and directories Git should ignore in the repository.

## Ignored Patterns

| Pattern | Description |
|---------|-------------|
| `.output` | Nuxt production build output |
| `.data` | Nuxt generated data |
| `.nuxt` | Nuxt dev/build cache |
| `.nitro` | Nitro server build |
| `.cache` | Cache directories |
| `dist` | Distribution builds |
| `node_modules` | NPM dependencies |
| `logs`, `*.log` | Log files |
| `.DS_Store` | macOS directory metadata |
| `.fleet`, `.idea` | IDE config directories |
| `.env`, `.env.*` | Environment files (local secrets) |
| `!.env.example` | Exception: keep env example |
